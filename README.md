# JavaScript Notes App

Project 6 of my 30 JavaScript Projects Challenge.

A clean and responsive Notes App built using HTML, CSS, and Vanilla JavaScript that allows users to create, edit, and manage notes with automatic data persistence using Local Storage.

---

## Features

- Create unlimited notes
- Edit notes in real time
- Delete notes with smooth animations
- Automatic saving using Local Storage
- Note titles and timestamps
- Dark mode toggle with theme persistence
- Responsive design for mobile and desktop
- Clean and minimal user interface

---

## Architecture Approach

The application uses dynamic DOM manipulation and Local Storage to manage notes and maintain application state.

- Users can create, edit, and delete notes
- Note data is stored locally using Local Storage
- Changes are saved automatically to maintain persistence
- Event delegation handles interactions across multiple notes
- CSS variables support theme switching between light and dark modes
- The interface updates dynamically as notes change

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API

---

## What I Learned

- Using Local Storage for persistent data
- Dynamic DOM creation and event delegation
- Managing multiple editable components
- Handling application state for creating, editing, and deleting notes
- Building reusable and scalable UI logic
- Designing responsive layouts with CSS
- Implementing theme switching with CSS variables
